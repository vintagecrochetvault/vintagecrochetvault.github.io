1. Operator and scope

Starnetos — VintageCrochetVault Analytics is operated by Martin Barros for the owner’s own business operations at VintageCrochetVault, an Etsy shop selling digital crochet patterns. It runs locally on the operator’s Windows computer. The application and its business information are not publicly accessible, and it is not a public SaaS service. Privacy contact: martinbalt.usa@gmail.com.

This policy describes the current preparation stage and the proposed Pinterest integration. Planned processing below has not yet begun through that integration. Application implementation details are based on information provided by the operator.

2. Current status and planned integration

The Etsy API integration currently uses OAuth and retrieves actual orders and listings. The Pinterest API integration is not implemented, authenticated, or connected to a Pinterest account. Starnetos is preparing its application for Pinterest API access; it does not claim approved access.

The initial Pinterest integration is planned to be read-only, for the owner’s account. It will support analytics reporting and content and editorial calendar preparation. Automatic publishing, Pin modification, and advertising management are outside this stage.

3. Planned information access

The intended analytics are impressions, saves, Pin clicks, outbound clicks, and historical performance. Exact endpoints, fields, and read-only authorization scopes have not yet been implemented. Any access will depend on the permissions and capabilities actually approved and granted. This policy will be updated to describe the implemented data flow before activation.

4. Planned use of information

The intended uses are the owner’s performance reporting, historical comparisons, and AI-assisted marketing recommendations and content planning. Historical retrieval and retention remain subject to Pinterest’s rules. This policy does not describe a currently implemented Pinterest–Etsy data combination.

5. Planned AI processing

Starnetos currently uses OpenAI models through Codex, authenticated using the operator’s ChatGPT subscription. The proposed Pinterest workflow would provide aggregated analytics to AI agents for reports and recommendations. OpenAI would therefore process any analytics supplied to those agents; this information would not remain exclusively on the operator’s computer. No other AI provider is currently planned for this integration.

This Pinterest-to-AI workflow is not active. Whether the proposed transfer is permitted by Pinterest, and the applicable provider data controls, retention, and model-training settings, remain to be reviewed before activation. This policy does not promise that provider processing is training-free or that aggregation alone permits disclosure. Provider processing is governed by the applicable service terms and settings.

6. Local storage and security

The application runs on the operator’s Windows computer. Initial Pinterest analytics and reports are planned to be stored in local project files, without adding a cloud database or other cloud storage service for this integration. The application is for the operator’s use and is not made available to the public.

Local storage does not mean that all processing is local: the proposed AI workflow involves OpenAI. This policy makes no claim that analytics files or reports are encrypted, that backups are absent, or that access can never occur. The token protection described below is distinct from protection of analytics files.

7. OAuth and token handling

The existing Etsy integration stores OAuth credentials and tokens outside the repository in Windows local application data, protected with Windows DPAPI using the CurrentUser scope. This describes the operator-reported Etsy implementation, not an implemented Pinterest safeguard.

The operator intends to use the same mechanism for Pinterest OAuth tokens. Pinterest token storage, authorization, refresh, and removal have not yet been implemented or verified. Pinterest authorization will be requested through its authorization process when implemented. This website does not connect accounts, collect Pinterest passwords, or handle OAuth tokens.

8. Retention and deletion

Local data and report files can currently be removed manually from the project’s files. There is no automated deletion system, definitive retention schedule, or verified procedure for removing every historical copy or backup. Deleting a working file does not establish deletion from version history, snapshots, reports, backups, or external provider records.

Before activating Pinterest, the operator must define and verify a deletion procedure covering data, snapshots, reports, copies, and OAuth tokens, together with revocation of access. No fixed deletion deadline, complete historical erasure, or deletion from OpenAI systems is promised. The Pinterest integration has not yet collected information to which a Pinterest retention period would apply.

9. Service providers and disclosures

OpenAI is the planned external processor of analytics submitted to AI agents. Public access to the application is restricted, but that restriction does not mean external providers cannot process information supplied to their services. No additional paid database or cloud storage service is planned for this integration.

Pinterest and Etsy provide their respective APIs under their own terms and privacy policies. Any future GitHub Pages publication concerns this informational website, not hosting of the local application or its analytics. This policy does not assert that the proposed Pinterest data transfer to OpenAI has been authorized by Pinterest.

10. Privacy questions and requests

Contact Martin Barros at martinbalt.usa@gmail.com to ask about information handled by Starnetos or to request access, correction, or deletion. Describe the relevant information and request without sending passwords or tokens. The operator can review requests and manually remove identified local project files, subject to the limitations above. There is no verified process guaranteeing removal of every historical or provider-held copy.

Any rights, verification requirements, and exceptions depend on applicable law. This policy does not waive applicable rights or certify compliance with any particular jurisdiction’s requirements.

11. Revoking Pinterest authorization

No Pinterest authorization is currently connected. If authorization is granted in the future, it can be revoked through Pinterest’s account settings for connected applications or app permissions. Revoking the grant and removing local tokens are separate from deleting retained data and reports. The complete local revocation and token-removal procedure must be verified before activation.

12. This informational website

The website’s own code sets no cookies and includes no third-party analytics, tracking scripts, application login, or Pinterest connection flow. It contains no private analytics or OAuth credentials. If hosted on GitHub Pages, GitHub may process visitor technical information under its privacy statement. The application’s local storage is separate from the website.

13. Policy updates and contact

This policy will be revised as the integration is implemented and before activating processing materially different from the preparation-stage description. Planned features are not statements that those features are currently operational.
