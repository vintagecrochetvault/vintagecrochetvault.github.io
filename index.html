A private, AI-assisted operations system for VintageCrochetVault, the business known as VintageCrochetVault | Vintage Crochet Patterns, an Etsy shop selling digital crochet patterns.

Pinterest integration in preparation. API access is being requested. The integration is not implemented or connected.

Built for the shop owner

Starnetos runs locally on the owner’s Windows computer. The existing Etsy OAuth integration retrieves orders and listings. Pinterest reporting is a planned addition.

The planned read-only Pinterest integration supports analytics reporting, performance comparisons, and content and editorial planning. It does not automatically publish Pins, modify Pinterest accounts, or manage advertising.

The application is not publicly accessible. Planned AI analysis would send aggregated analytics to OpenAI through Codex. This website provides public information about the application and its privacy practices.
